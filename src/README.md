# Library source code

* `forcolormap.f90`: the Colormap class and the `colormaps_list`.
* `forcolormap_parameters.f90`: a few parameters used in several modules of the library.
* `forcolormap_utils.f90`: contains miscellaneous procedures and functions.
* `forcolormap_info.f90`: the Colormaps_info class offers information about each colormap.
* The modules containing the different collections of colormaps:
  * `forcolormap_cm_scientific.f90`
  * `forcolormap_cm_matplotlib.f90`
  * `forcolormap_cm_miscellaneous.f90`
